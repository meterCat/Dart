# Dart —— RoboMaster 视觉自瞄系统

基于 C++ 的 RoboMaster（机甲大师）飞镖（Dart）视觉自瞄系统。通过海康工业相机采集图像，使用 OpenVINO 推理检测目标**引导灯**，经跟踪滤波后解算出云台 `yaw` 偏差，再通过串口下发给电控，实现对目标的自动瞄准与跟随。

## 功能特性

- **相机采集**：海康机器人工业相机（HikRobot SDK），支持触发模式、分辨率/ROI 配置
- **目标检测**：OpenVINO 神经网络推理，检测引导灯目标并输出包围盒与置信度
- **目标跟踪**：目标缓存 + 丢帧处理 + OneEuro 滤波，解算 `yaw` 偏差与速度
- **串口通信**：与电控自定义协议通信（含 CRC8 / CRC16 校验）
- **数据录制**：MCAP 格式（Foxglove）录制与回放，便于赛后复盘分析
- **调试工具**：鼠标框选目标、可视化绘制
- **高性能并发**：线程池 + 无锁栈（lock-free）实现多级流水线

## 整体框架

系统采用多线程流水线，各线程之间通过无锁栈（`LfStack`）传递数据：

```
[海康相机]  →  FromData  →  [检测 Detect]  →  ImageInfo  →  [跟踪 Track]  →  VisionData  →  [串口/电控]
                                │                                                        │
                                └────────────  MouseInfo  →  [鼠标 Mouse]                └─→ [录制 Capture] → MCAP
```

主要线程（见 `main.cpp`）：

| 线程 | 模块 | 作用 |
|------|------|------|
| `receive` | 海康相机 | 采集图像并送入 `FromData` 队列 |
| `detect` | `Detect` | OpenVINO 推理，检测引导灯，输出 `ImageInfo` |
| `track` | `Track` | 目标跟踪滤波，解算 `yaw` 偏差，串口下发 `VisionData` |
| `mouse` | `Mouse` | 鼠标框选目标与可视化调试 |
| `capture` | `Capture` | 将结果录制为 MCAP 数据包 |

## 目录结构

```
├── main.cpp            程序入口，组织多线程流水线
├── config/
│   ├── json/           各模块 JSON 配置（检测/跟踪/串口/录制等）
│   ├── openvino/       OpenVINO 模型（Katrin.xml / Katrin.bin）
│   └── flatbuffers/    FlatBuffers 数据结构定义（.fbs）
├── src/
│   ├── threads/        线程池与无锁栈
│   ├── sensors/        相机采集与串口通信
│   ├── detect/         目标检测（OpenVINO）
│   ├── track/          目标跟踪与滤波
│   ├── mouse/          鼠标控制与调试
│   ├── capture/        MCAP 录制
│   └── utility/        工具库（JSON、FlatBuffers、MCAP 读写等）
└── CMakeLists.txt
```

## 依赖

- C++（CMake ≥ 3.25）
- OpenCV
- OpenVINO
- FlatBuffers
- MCAP（头文件已内置）
- 海康机器人相机 SDK（`MvCameraControl`）

## 编译运行

```bash
cmake -B build
cmake --build build
./build/Dart
```

串口需提前赋予权限：

```bash
sudo chmod 666 /dev/ttyACM0
```

重新生成 FlatBuffers 序列化代码（需安装 `flatc`）：

```bash
flatc --binary --schema -o config/autogenerated_flatbuffers/ CaptureInformation.fbs
```

## 运行前检查

1. 代码需在比赛前提前烧录
2. 确认相机安装位置，能否直接瞄准目标
3. 确认相机没有装反（装反会导致图像颠倒）
4. 确认串口与线缆连接正常
